# 📚 BookNest — Library Management System

A modern, responsive, and lightweight **Library Management System** built with **HTML, CSS, and JavaScript**.

**BookNest** provides a simple interface for managing books, with support for adding books, viewing dynamically stored books, and persisting data using the browser's **LocalStorage**.

---

## ✨ Features

* 🔐 Simple login interface
* ➕ Add new books
* 📖 View books dynamically
* 💾 Persistent data using LocalStorage
* 🎨 Modern and responsive user interface
* 📱 Mobile-friendly design
* ⚡ Fast and lightweight
* 🧩 Simple client-side architecture
* 🌐 Runs directly in the browser

---

## 🔄 How It Works

The application follows a simple client-side workflow:

```text
        ┌──────────────┐
        │   Login Page │
        └──────┬───────┘
               │
               ▼
        ┌──────────────┐
        │  Home Page   │
        └──────┬───────┘
               │
       ┌───────┴────────┐
       ▼                ▼
┌─────────────┐  ┌─────────────┐
│  Add Books  │  │ View Books  │
└──────┬──────┘  └──────┬──────┘
       │                │
       └───────┬────────┘
               ▼
       ┌───────────────┐
       │  LocalStorage │
       └───────────────┘
```

Books added through the application are stored in the browser's **LocalStorage**, allowing the data to remain available after refreshing the page.

## 🚀 Getting Started

### Prerequisites

No backend server or database is required.

You only need:

* A modern web browser
* Git *(optional, for cloning the repository)*

---

### 1️⃣ Clone the Repository


---

### 2️⃣ Navigate to the Project

```bash
cd BookNest-Library-Management-System
```

---

### 3️⃣ Run the Application

